# OpenStreetMap: licence and download rules (read November 21st 2026)

Read from the pages themselves (handover §8 and §10 step 2), quoted where it matters.

## The credit (openstreetmap.org/copyright and the Attribution Guidelines)

1. "Where you use OpenStreetMap data, you are required to do the following two things: Provide
   credit to OpenStreetMap by displaying our attribution notice. Make clear that the data is
   available under the Open Database License."
2. "Attribution must be to 'OpenStreetMap'. … This may be done by making the text 'OpenStreetMap'
   a link to openstreetmap.org/copyright".
3. "Attribution must be placed in the vicinity of the produced work or in a location where
   customarily attribution would be expected by the users of the produced work."
4. For routing engines (the nearest case to ours): "Applications that incorporate such a routing
   engine must credit OpenStreetMap. Routing instructions generated by such a routing engine need
   not maintain attribution attached to the instructions, as long as they do not form a
   Derivative Database."

So: a line in "About these figures" with "OpenStreetMap" linking to openstreetmap.org/copyright
looks enough; each sentence needn't carry it. Wording to agree with John.

## The table (the Produced Work guideline)

5. "If the published result of your project is intended for the extraction of the original data,
   then it is a database and not a Produced Work." The table is a small database made from the
   map, published in the page's code and the public repo, so it's a Derivative Database: "need to
   be made available on ODbL terms if publicly used."
6. For databases the guidelines ask for the licence's text or a link to it "in a location (such as
   a relevant directory) where users would be likely to look for it, such as a readme file, or
   within the data or metadata."

So: the table goes under the Open Database Licence, with a short notice beside it in the repo
(and perhaps a line inside the file). The rest of Trainchecker's code isn't affected. Not legal
advice; Claude's reading.

## Getting the data (API usage policy, operations.osmfoundation.org)

7. "The editing API is provided in order to edit the map data, not for read-only purposes or
   projects." "Large or frequent data users must use the download service 'planet.osm' or other
   alternatives", which it lists: planet.osm and its extracts by area, and Overpass.

So: no more boxes from api.openstreetmap.org (the six earlier ones were small, one at a time).
The whole table is built from a downloaded United Kingdom extract
(download.openstreetmap.fr, dated November 21st 2026; download.geofabrik.de and overpass-api.de
dropped every connection from this environment).
